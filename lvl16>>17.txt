# Level 16 → 17

## Goal
Scan ports 31000-32000 on localhost to find which one speaks SSL, submit the current 
password to it, and receive an SSH private key for the next level.

## Commands used
```bash
ssh bandit16@bandit.labs.overthewire.org -p 2220
nmap -p 31000-32000 localhost
openssl s_client -connect localhost:31790 -quiet
# paste bandit16's password when connected
# save the returned private key:
mkdir /tmp/mykeys
nano /tmp/mykeys/bandit17.key
# paste the key, save, then:
chmod 400 /tmp/mykeys/bandit17.key
```

## Key concepts
| Term | Meaning |
|---|---|
| `nmap` | Network mapper — scans ports to see which ones are open/listening |
| `-p 31000-32000` | Only scan this specific port range |
| Port scanning | Probing a range of ports to discover which services are running |
| SSH private key | Returned instead of a plain password this time |
| `chmod 400` | Makes the key file read-only by owner — required for SSH to accept it |

## Explanation
This level combines port scanning with SSL — first `nmap` identifies which ports in the 
range are open, then `openssl s_client` is used to test which one speaks SSL and accepts 
the password. The correct port responds with an SSH private key instead of a plain 
password, which is saved to a temp file with restricted permissions (`chmod 400`) so SSH 
will actually accept it for the next level's login.
